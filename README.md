# Bar à cocktails

Projet de programmation Python simulant le fonctionnement
d'un bar à cocktails.

## Description

L'application simule les interactions entre les employés
d'un bar et les clients.

Le bar fonctionne avec :
- Un ou plusieurs serveurs
- Un bariste
- Un pic contenant les commandes à préparer
- Un bar contenant les commandes prêtes à être servies

## Objectifs

- Utiliser la programmation orientée objet
- Manipuler des files de commandes
- Enregistrer les actions dans des logs
- Implémenter la concurrence avec asyncio
- Synchroniser les tâches avec asyncio.Lock

## Technologies

- Python 3
- asyncio
- Git
